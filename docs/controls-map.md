## Limitations

1. **DNS Pinning Scope**: The DNS-pinning mechanism in `app/security/ssrf.py` uses a thread-locked context manager patching `socket.getaddrinfo`. In single-process or multi-threaded WSGI deployments (e.g. Gunicorn with gthread), the lock guarantees thread-safe socket pinning. In async event-loop workers (e.g. gevent), an HTTP proxy or custom transport adapter would be preferred.
2. **In-Memory Rate Limiter in Dev/Test**: By default, Flask-Limiter uses `memory://` storage. In production multi-process clusters, `RATELIMIT_STORAGE_URI` should point to a vetted Redis instance (`redis://...`) with TLS.
3. **Link Preview Content Parsing**: Preview extraction intentionally limits parsing strictly to `<title>` and `<meta name="description">` to minimize parser attack surface. JavaScript-rendered SPAs (Client-Side Rendering) will not expose titles unless pre-rendered.
